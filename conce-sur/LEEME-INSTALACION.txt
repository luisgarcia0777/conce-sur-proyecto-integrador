CONCE SUR - INVENTARIO CON PERSISTENCIA (PROTOTIPO LOCAL)

Qué incluye
- Inventario con consulta, registro, búsqueda, filtros por tipo/ubicación y eliminación segura de productos sin historial asociado.
- Ventas con guardado en base de datos, número de venta, validación de stock y descuento transaccional de unidades.
- Servicios con registro, búsqueda por texto/estado y actualización del estado.
- Dashboard con indicadores, stock bajo y servicios abiertos consultados desde la base de datos.
- Consultas preparadas PDO, escape HTML, validaciones de campos y tokens CSRF en los formularios que modifican datos.

Instalación en WAMP
1. Descomprime la carpeta conce-sur dentro de C:\\wamp64\\www\\ para que quede C:\\wamp64\\www\\conce-sur\\index.php.
2. Inicia WAMP y comprueba que Apache y MySQL/MariaDB estén activos.
3. Abre http://localhost/phpmyadmin/.
4. En la pestaña Importar, selecciona conce-sur/database/conce_sur.sql y ejecútalo. El script crea la base de datos conce_sur, la tabla productos y registros marcados como DEMO.
5. Revisa conce-sur/config/database.php. La configuración inicial usa host 127.0.0.1, base conce_sur, usuario root y contraseña vacía (común en WAMP local; cambia si tu instalación usa otra).
6. Abre http://localhost/conce-sur/pages/inventario.php.
7. Registra un producto con código único, actualiza la página y confirma que permanece. Prueba también buscar y filtrar.

Evidencia real que debes capturar
A. Pantalla del inventario con el producto de prueba guardado.
B. phpMyAdmin mostrando la fila correspondiente en la tabla productos.
C. Búsqueda o filtro aplicado.
D. Si ocurre error, captura el mensaje y corrige antes de afirmar que funciona.

Notas académicas y técnicas
- Esta entrega conecta el módulo de inventario a MySQL/MariaDB para una demostración local en WAMP. Si el documento del proyecto declara PostgreSQL/Laravel como arquitectura objetivo, no afirmes que esta implementación ya usa ese stack: documenta la diferencia como prototipo de validación o migra antes de la entrega si el docente exige estrictamente la tecnología objetivo.
- Los cuatro registros de ejemplo están identificados con prefijo DEMO y observaciones de prueba. No representan inventario verificado de CONCE SUR.
- No hay autenticación implementada. La etiqueta Administrador es solo visual; no es un control de acceso.
- Eliminar borra el registro de la base de datos. Úsalo solo con datos de prueba mientras validas.
- No subir credenciales de una base de datos real a un repositorio público.


VENTAS CON CONTROL DE STOCK
---------------------------
La página pages/ventas.php ahora guarda ventas, registra un número de operación y descuenta unidades del producto dentro de una transacción. También muestra las últimas 15 ventas y el resumen del día.

IMPORTANTE: si ya importaste una versión anterior de database/conce_sur.sql, vuelve a importar el archivo actualizado en phpMyAdmin. Como las tablas usan CREATE TABLE IF NOT EXISTS, no elimina los productos existentes y agrega la tabla ventas que falta. No vuelvas a cargar datos de inventario real sin revisar primero qué contiene el archivo.

PRUEBA RECOMENDADA
1. En Inventario, registra un producto de prueba con un código claro, por ejemplo TEST-VENTA-01, y stock 5.
2. En Ventas, registra 2 unidades con un nombre de cliente ficticio de prueba.
3. Confirma que la venta aparece en la tabla y que el stock del producto pasó de 5 a 3.
4. Intenta vender más unidades de las disponibles y confirma que el sistema no guarda la venta.
5. Toma capturas reales de la pantalla y de phpMyAdmin solo después de ejecutar las pruebas.

LIMITACIONES ACTUALES
- Cada venta registra un solo producto. Para una nota de venta con múltiples líneas hace falta separar cabecera de venta y detalle de venta.
- Los datos del cliente se registran en cada venta; aún no hay un módulo Clientes normalizado.
- No hay autenticación real de usuarios, comprobantes electrónicos SUNAT ni integración SUNAT.
- Esta versión usa PHP y MySQL/MariaDB para una implementación local en WAMP; no es todavía la arquitectura Laravel/PostgreSQL propuesta en el documento académico.


SERVICIOS Y DASHBOARD DINÁMICO
------------------------------
La página pages/servicios.php permite registrar servicios, consultarlos por estado/texto y cambiar su estado entre Pendiente, En revisión y Finalizado. El panel index.php obtiene sus indicadores, lista de stock bajo y servicios abiertos desde la base de datos.

Si ya habías importado una versión anterior del SQL, importa de nuevo el archivo actualizado para crear la tabla servicios.
